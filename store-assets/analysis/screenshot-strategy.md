# MapMeet — Screenshot Campaign Strategy

Six App Store screens and six Google Play screens telling one story:
**see what's near you → decide → join → you're already in the conversation →
host your own → the map remembers you.**

Canvas: App Store iPhone `1320 × 2868`, Google Play phone `1080 × 1920`.
The Play set is **recomposed**, not resized: it is shorter and wider in
proportion, so headlines drop to two lines max and the device sits higher.

---

## Cross-screen continuity

A single **indigo hairline path** — the same stroke weight and colour as a map
route — enters screen 01 from the bottom-left, travels behind the device on
every screen, and exits screen 06 at the top-right. Screens 01–03 sit on paper
`#F6F4EE`; screen 04 flips to ink `#0E0E10` to mark the "you're in" turn; screens
05–06 return to paper. Headline baseline is identical on all six.

## SCREEN 01 — Core promise

**Asset:** `appstore_iphone_01.png` · `googleplay_phone_01.png`
**Purpose:** Establish the one-line promise and show the product's signature
surface within the first second of the store listing.
**Headline:** `Everything happening near you.`
**Subheadline:** `On one live map.`
**Source screenshot:** `raw-ios/05-map-hero.png`
**App screen / state:** Map tab, central Kyiv, ~9 clustered and single pins
visible, search field and filter row unobstructed, "Live jazz in the yard"
label legible, coral create FAB bottom-right.
**Background:** Paper `#F6F4EE`, indigo path entering bottom-left.
**Composition:** Headline block top ~14 % of canvas, left-aligned to the 8 %
gutter. Device below, centred, cropped at the bottom edge so the UI runs off
canvas — signals "there's more".
**Device / UI position:** Framed in a thin ink bezel, occupying ~76 % of width.
**Decorative:** Indigo route path; one −4° rounded-square pin motif echoing the
app's marker, top-right, at low opacity.
**Why this screen matters:** It is the product in one image. If a browser only
sees screen 01, they still understand MapMeet.

## SCREEN 02 — Decide

**Asset:** `appstore_iphone_02.png` · `googleplay_phone_02.png`
**Purpose:** Show that a pin is a real, complete event — and that joining is one
tap.
**Headline:** `Tap a pin. Know everything.`
**Subheadline:** `Time, place, host, who's going.`
**Source screenshot:** `raw-ios/06-event-preview-hosting.png`
**App screen / state:** Map with the event preview sheet open on "Rooftop sunset
coffee" — indigo date pill, `1.2 KM AWAY`, host line, address link, description,
four attendee avatars, "4 going".
**Background:** Paper, indigo path continuing from screen 01.
**Composition:** Headline top, device below with the **bottom sheet aligned to
the optical centre** so the attendee row and action buttons land in the reader's
eye line.
**Decorative:** None beyond the continuing path — the sheet is busy enough.
**Why this screen matters:** Converts curiosity into confidence. Answers "is
this a real thing with real people?"

## SCREEN 03 — Discover nearby

**Asset:** `appstore_iphone_03.png` · `googleplay_phone_03.png`
**Purpose:** Prove the "near you" claim with a number, and show the list side of
the product for people who don't think in maps.
**Headline:** `47 events within 5 km.`
**Subheadline:** `Tonight, tomorrow, this weekend.`
**Source screenshot:** `raw-ios/10-events-nearby.png`
**App screen / state:** Events → Nearby, radius selector on 5 km, header reading
`47 WITHIN 5 KM`, four event cards with emoji tiles, indigo date pills, tags and
`Join event` buttons.
**Background:** Paper; the indigo path passes behind the device and turns
upward.
**Composition:** Headline top; the numeral `47` set in the same weight as the
rest of the line — no oversized stat callout, the app is too restrained for that.
**Decorative:** A faint concentric radius ring behind the device, indigo at ~8 %
opacity, referencing the radius control.
**Why this screen matters:** Specificity beats adjectives. A real count from the
real database is more persuasive than "lots of events".

## SCREEN 04 — You're already in

**Asset:** `appstore_iphone_04.png` · `googleplay_phone_04.png`
**Purpose:** Land the strongest differentiator — join and you're in the group
chat, no extra step.
**Headline:** `Join, and you're in the chat.`
**Subheadline:** `Every event gets its own group.`
**Source screenshot:** `raw-ios/08-chat-thread.png`
**App screen / state:** The "Rooftop sunset coffee" group chat — header with
emoji avatar, `MON, 10 AUG · 19:30 · 4 GOING / 12`, ink outgoing bubbles, panel
incoming bubbles with indigo sender names, coral system pills, composer.
**Background:** **Ink `#0E0E10`** — the one dark screen in the set, marking the
narrative turn from "browsing" to "belonging". Headline in paper `#F5F5F2`.
**Composition:** Headline top; device large and slightly closer to the reader
(~80 % width) so individual messages are readable at store thumbnail size.
**Decorative:** Indigo path continues in a lighter tint against the ink.
**Why this screen matters:** This is the feature no competitor screenshot shows.
It is the reason to choose MapMeet over a calendar.

## SCREEN 05 — Host your own

**Asset:** `appstore_iphone_05.png` · `googleplay_phone_05.png`
**Purpose:** Flip the reader from consumer to creator, and show how little
effort it takes.
**Headline:** `Drop a pin. Start a plan.`
**Subheadline:** `Hosting takes about a minute.`
**Source screenshot:** `raw-ios/22-create-pin-placement.png`
**App screen / state:** Map in pin-placement mode — ink banner "Tap the map to
pin the event · Cancel", coral pending marker with the "New event here" pill,
coral FAB.
**Background:** Paper; the path arrives at the coral marker, making the marker
the terminus of the line the reader has followed since screen 01.
**Composition:** Headline top; device positioned so the **coral marker sits on
the composition's optical centre** — the only strong colour in the frame.
**Decorative:** Path terminus; nothing else.
**Why this screen matters:** Supply-side acquisition. Hosts bring their friends,
and this is the screen that recruits them.

## SCREEN 06 — Who you'll meet

**Asset:** `appstore_iphone_06.png` · `googleplay_phone_06.png`
**Purpose:** Close on trust and identity — the answer to "who are these people?"
**Headline:** `Real profiles. Real ratings.`
**Subheadline:** `See who you're meeting before you go.`
**Source screenshot:** `raw-ios/11-profile-you.png`
**App screen / state:** The "You" tab — large indigo initials avatar, name and
`@handle`, `Edit profile / Friends / Settings` row, the four stat tiles including
`5.00 RATING`, bio, six emoji interest chips, `Hosting · 6` tab with event cards.
**Background:** Paper; the indigo path exits top-right, closing the series.
**Composition:** Headline top; device centred; the stat tiles and interest chips
in the upper two-thirds of the visible UI.
**Decorative:** Path exit; a small ink "M" monogram lockup with the wordmark
**MapMeet** below the device — the only place the brand mark is stated outright.
**Why this screen matters:** Final impression. Trust is the last objection before
download for anything that involves meeting strangers.

---

## Google Play recomposition notes

`1080 × 1920` is proportionally shorter (1.78 vs 2.17). Per screen:

- Headline drops to **two lines maximum**; subheadline stays one line.
- Type scale reduces to ~78 % of the App Store size so the ratio of text block
  to device stays constant.
- The device is **cropped harder at the bottom** (roughly 12 % more) rather than
  scaled down, keeping the UI readable at Play's smaller thumbnail.
- The indigo path is re-drawn at the new aspect, not stretched.
- Screen 06's monogram lockup moves from below the device to the top-right of
  the headline block, where there is room.
